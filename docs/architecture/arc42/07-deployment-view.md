# 7. Развёртывание

На текущем этапе MILVIV разворачивается **только локально**, на машине разработчика. Решение о продуктивном окружении не принято.

## Локальное окружение

```
┌──────────────── машина разработчика ────────────────┐
│                                                     │
│   JVM (Java 25)                    PostgreSQL       │
│   ┌──────────────────┐             ┌────────────┐   │
│   │ MILVIV           │   JDBC      │            │   │
│   │ Jetty :<port>    ├────────────►│            │   │
│   │ HikariCP         │             │            │   │
│   └──────────────────┘             └────────────┘   │
│           │                                         │
│           │ .env (секреты, вне репозитория)         │
└───────────┼─────────────────────────────────────────┘
            │ HTTPS
            ▼
      Google Gemini
```

| Элемент | Назначение |
| ------- | ---------- |
| JVM 25 | Среда выполнения; версия задана toolchain в `build.gradle` |
| Jetty | Встроенный HTTP-сервер, запускается из `Main` — отдельный контейнер сервлетов не нужен |
| PostgreSQL | Хранение данных; схема приводится в актуальное состояние миграциями Flyway при старте |
| `.env` | Конфигурация и секреты, загружаются через dotenv-java; в репозиторий не попадают (OC-01) |

Артефакт сборки — fat JAR (задача `fatJar` в `build.gradle`) с точкой входа `com.milviv.presentation.Main`.

## Порядок запуска

Определён в `Main` и состоит из трёх фаз: регистрация зависимостей → создание графа, поднятие пула соединений, применение миграций → health check БД, регистрация контроллеров, старт Jetty. Остановка выполняется через shutdown hook: сначала HTTP-сервер, затем пул соединений.

## Не решено

Продуктивное развёртывание: площадка, контейнеризация, резервное копирование БД, управление секретами вне `.env`. См. раздел 11.
