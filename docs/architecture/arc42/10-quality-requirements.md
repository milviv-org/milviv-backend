# 10. Требования к качеству

Цели качества описаны в [разделе 1.2](01-introduction-and-goals.md) и здесь не дублируются. Ниже — их связь с решениями и признаки нарушения.

| Цель | Приоритет | Решение | Нарушено, если |
| ---- | --------- | ------- | -------------- |
| QG-01 Конфиденциальность | критический | Фильтрация по `user_id` на уровне запроса к БД; детали ошибок не уходят наружу | Запрос без фильтра по владельцу вернул чужие данные; текст внутреннего исключения попал клиенту |
| QG-02 Полезность AI-анализа | высокий | AI получает данные только по явному запросу из закрытого каталога | Ответ AI не учитывает контекст данных пользователя |
| QG-03 Целостность экономики | критический | Транзакция + оптимистичные блокировки; `points_history` как источник правды | Задача выполнена без начисления баллов; повторное начисление за одно событие; отрицательный баланс |
| QG-04 Сохраняемость истории задач | высокий | Append-only записи: факт выполнения, план против факта, переносы | Изменение состояния задачи стёрло плановую дату или историю переносов |
| QG-05 Поддерживаемость | высокий | Слои с однонаправленной зависимостью + деление по предметным областям | `domain` импортирует `infrastructure`; область правится при изменении соседней |

Подробные механизмы — [раздел 8](08-crosscutting-concepts.md). Реестр решений — [раздел 9](09-architecture-decisions.md).
