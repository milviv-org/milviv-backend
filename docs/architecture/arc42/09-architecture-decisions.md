# 9. Архитектурные решения

Реестр принятых решений со ссылками на место, где они обоснованы. Обоснования не дублируются — раздел служит оглавлением и хронологией.

| # | Решение | Причина | Где описано |
| - | ------- | ------- | ----------- |
| AD-01 | Backend на чистой Java без Spring | Учебная цель — понять механизмы, скрытые фреймворком | [2.1 LC-01…LC-03](02-constraints.md) |
| AD-02 | Слоёная архитектура, слои первичны, предметные области вторичны | Без фреймворка границы задаются явно (QG-05) | [4.1](04-solution-strategy.md), [5.1](05-building-blocks.md) |
| AD-03 | `shared` вне цепочки слоёв, зависимости только внутрь | Инструменты общего назначения не должны зависеть от предметной области | [5.1](05-building-blocks.md) |
| AD-04 | Самописные DI-контейнер, роутер, менеджер транзакций, валидация | LC-03; готовые библиотеки — только там, где нет учебной ценности | [4.1](04-solution-strategy.md) |
| AD-05 | PostgreSQL + HikariCP + Flyway + Jetty + Jackson + BCrypt | Выбор по каждой позиции | [TECHNOLOGY_DECISIONS.md](../../TECHNOLOGY_DECISIONS.md) |
| AD-06 | Оптимистичные блокировки вместо пессимистичных | Персональный инструмент, конкуренция за данные редка | [4.4](04-solution-strategy.md), [8.1](08-crosscutting-concepts.md) |
| AD-07 | Один механизм для AR-01 и QG-03 | Отдельные решения для конкурентности и целостности баллов не нужны | [4.4](04-solution-strategy.md) |
| AD-08 | Граница транзакции — прикладной сценарий | Репозиторий не обеспечит атомарность двух агрегатов; контроллер удерживал бы соединение во время вызова Gemini | [5.2](05-building-blocks.md), [8.1](08-crosscutting-concepts.md) |
| AD-09 | Транзакция объявляется явным вызовом, не аннотацией | Границы видны в коде, нет «магии» через прокси (LC-03) | [8.1](08-crosscutting-concepts.md) |
| AD-10 | Три уровня валидации с общим нижним | Правило должно вести себя одинаково в аннотациях и в процедурной проверке | [8.2](08-crosscutting-concepts.md), [concepts/validation.md](concepts/validation.md) |
| AD-11 | Единая иерархия исключений `AppException`; всё прочее → 500 без деталей | Предсказуемый контракт API, детали системы не утекают (QG-01) | [8.3](08-crosscutting-concepts.md) |
| AD-12 | `AppException` в `domain` зависит от `org.slf4j.event.Level` | Осознанный компромисс: SLF4J — фасад, уровень лога — часть смысла ошибки | [8.3](08-crosscutting-concepts.md) |
| AD-13 | Доступ к `DIContainer` только из composition root | Запрет Service Locator — зависимости видны в сигнатуре класса | [8.4](08-crosscutting-concepts.md) |
| AD-14 | Изоляция данных фильтрацией по `user_id` на уровне запроса к БД | Выборка физически не может вернуть чужие данные (QG-01, AR-02) | [4.4](04-solution-strategy.md) |
| AD-15 | AI возвращает данные, а не выполняет действия; команд пользователя нет, данные AI получает только по явному запросу | Рамку задают каталог данных, лимиты сервера и подтверждение пользователя; ответ AI проходит валидацию | [4.5](04-solution-strategy.md), [concepts/ai-assistant/](concepts/ai-assistant/README.md) |
| AD-16 | `points_history` — источник правды для баланса баллов | Целостность игровой экономики (QG-03) | [1.2 QG-03](01-introduction-and-goals.md) |
| AD-17 | Индексация БД по access pattern | Производительность пользовательских операций | [decisions/tasks-access-pattern.md](../../decisions/tasks-access-pattern.md) |
| AD-18 | Изменение и удаление через AI — только по явному согласию пользователя на каждую операцию | Разрушительные действия не исполняются по решению модели; пользователь видит список затронутых сущностей (из БД), после исполнения — отчёт со ссылками | [4.5](04-solution-strategy.md), [concepts/ai-assistant/](concepts/ai-assistant/README.md) |
| AD-19 | Скрытые награды недоступны AI полностью | Скрытость — защита пользователя, AI не должен знать даже о существовании | [4.5](04-solution-strategy.md) |
| AD-20 | AI работает на бесплатном тарифе Gemini | Никто не платит; при исчерпании квоты ждём сброса | [concepts/ai-assistant/](concepts/ai-assistant/limits-and-security.md) §8 |
| AD-21 | Создание через AI — без подтверждения | Создание ничего не портит; защита — лимиты | [decisions.md](concepts/ai-assistant/decisions.md) |
| AD-22 | Согласие на использование данных AI — один раз, хранится на сервере | Без согласия AI недоступен и во фронтенде, и на сервере | [concepts/ai-assistant/](concepts/ai-assistant/user-flow.md) §6.10 |
| AD-23 | Лимиты AI — в конфиге с дефолтами | Как `AppConfig`; меняются без изменения кода | [concepts/ai-assistant/](concepts/ai-assistant/limits-and-security.md) §8 |
| AD-24 | Access — JWT HS256 на 15 минут, refresh — непрозрачный токен с ротацией и отзывом сессии при повторном использовании | Короткий access без хранения; refresh можно отозвать | [concepts/authentication.md](concepts/authentication.md) |
| AD-25 | Токены только в HttpOnly-cookie `Secure; SameSite=Strict` | Защита от кражи через XSS и от CSRF | [concepts/authentication.md](concepts/authentication.md) |
| AD-26 | Маршруты закрыты по умолчанию, открытые — `@Public` | Забытая проверка не открывает данные (AR-05) | [8.6](08-crosscutting-concepts.md) |
