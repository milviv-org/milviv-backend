# 12. Глоссарий

## Предметная область

| Термин | Значение |
| ------ | -------- |
| **Цель** | Долгосрочный результат, к которому движется пользователь. Декомпозируется на проекты и задачи |
| **Проект** | Группа задач, служащая достижению цели. Может существовать без цели |
| **Задача** | Конкретное действие со сроком и уровнем сложности. За выполнение начисляются баллы |
| **Уровень сложности** | Характеристика задачи, определяющая количество начисляемых баллов |
| **План** | Привязка задачи к конкретному дню выполнения |
| **Перенос** | Изменение плановой даты задачи. Фиксируется в истории (QG-04) |
| **Балл** | Единица внутренней валюты. Начисляется за выполнение задачи, тратится на награды |
| **Баланс** | Текущее количество баллов пользователя. Источник правды — история операций, а не отдельное поле |
| **Награда** | Созданный пользователем объект со стоимостью в баллах |
| **Рефлексия** | Ответы пользователя на вопросы после выполнения задачи. Материал для поиска закономерностей |
| **AI-предложение** | То, что AI хочет сделать: создать, изменить, удалить. Создания выполняются сразу, изменения и удаления — после подтверждения |
| **Карточка подтверждения** | Список изменений и удалений от AI с галочками в сообщении чата |
| **Отчёт** | Список сущностей, созданных, изменённых или удалённых по запросу к AI, со ссылками |
| **Запрос данных AI** | Типизированный запрос AI к закрытому каталогу данных. Сервер исполняет его только для текущего пользователя |
| **Дескриптор** | Случайная ссылка на существующую сущность (`t_9fLm`), которую сервер выдаёт AI вместо реального ID. Действует в рамках одного AI-запроса |
| **Согласие на изменение** | Явное перечисление пользователем изменений и удалений из AI-предложения, которые разрешено исполнить. Неперечисленные отменяются |

## Архитектура

| Термин | Значение |
| ------ | -------- |
| **Слой** | Верхний уровень деления кода: `domain`, `application`, `infrastructure`, `presentation`. Зависимости однонаправлены |
| **Предметная область** | Деление внутри слоя: `task`, `project`, `goal` и т. д. |
| **Агрегат** | Доменный объект, изменяемый как единое целое. Носит номер версии |
| **Прикладной сценарий** | Действие пользователя в слое `application`. Задаёт границу транзакции |
| **Composition root** | `Main` — единственное место, где известны конкретные реализации интерфейсов |
| **Оптимистичная блокировка** | Обнаружение конкурентного изменения сравнением версии агрегата вместо блокировки строки |
| **Propagation** | Правило присоединения к существующей транзакции |
| **Уровень изоляции** | Степень защиты транзакции от эффектов параллельных транзакций |
| **Append-only** | Способ хранения, при котором записи только добавляются, но не изменяются и не удаляются |
| **Сквозная концепция** | Решение, затрагивающее несколько блоков сразу. Описано в [разделе 8](08-crosscutting-concepts.md) |
