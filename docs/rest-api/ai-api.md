# AI API

AI-ассистент текущего пользователя. Все маршруты требуют входа. Общие правила и ошибки — [README.md](README.md). Архитектура — [concepts/ai-assistant/](../architecture/arc42/concepts/ai-assistant/README.md).

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | [/ai/consent](#get-aiconsent) | Дано ли согласие на использование данных |
| POST | [/ai/consent](#post-aiconsent) | Дать согласие |
| POST | [/ai/requests](#post-airequests) | Отправить сообщение AI |
| GET | [/ai/requests](#get-airequests) | История запросов |
| GET | [/ai/requests/{id}](#get-airequestsid) | Один запрос |

Все `/ai/requests*` без согласия отвечают `403 AI_CONSENT_REQUIRED`, и данные к провайдеру не уходят.

> **Пока нет настоящего AI.** Адаптер Gemini появится в подэтапе 9.6. До тех пор `POST /ai/requests` записывает запрос и отвечает `503 AI_PROVIDER_UNAVAILABLE`.

## Согласие

Даётся один раз и действует бессрочно; отозвать нельзя. Покрывает чтение всех категорий данных, которые может запросить AI: задачи, проекты, награды (кроме скрытых), рефлексия, планы, цели. Это **не** подтверждение операций: изменения и удаления AI подтверждаются в каждом предложении отдельно.

Текст окна согласия показывает фронтенд. В нём должно быть: какие данные читает AI, что они передаются Google Gemini, что тариф бесплатный и Google может использовать данные по своим условиям.

```json
{ "accepted": true, "acceptedAt": "2026-10-11T12:00:00Z" }
```

`acceptedAt` — `null`, если согласия нет.

## Запрос к AI (ответ)

```json
{
  "requestId": "7f9e…",
  "status": "ANSWERED",
  "summary": null,
  "answer": "Чаще всего просрочены задачи по грамматике",
  "clarificationQuestion": null,
  "errorCode": null,
  "refusalReason": null,
  "report": [],
  "dataAccessed": [ { "query": "LIST_TASKS", "items": 12, "reason": "Найти просроченные задачи" } ],
  "createdAt": "2026-10-11T12:00:00Z"
}
```

| `status` | Что значит | Заполнено |
|----------|------------|-----------|
| `PENDING_AI` | AI ещё отвечает | — |
| `ANSWERED` | Текстовый ответ, ничего не изменено | `answer` |
| `EXECUTED` | AI предложил создать цели, проекты, задачи, награды — **всё уже создано** (подтверждать создания не нужно) | `summary`, `report`, по желанию AI — `answer` |
| `NEEDS_CLARIFICATION` | AI задал вопрос. Истории диалога нет: дополните исходный текст и отправьте новый запрос | `clarificationQuestion` |
| `FAILED` | Не удалось — см. код | `errorCode`; для отказа ещё `refusalReason` |

Остальные статусы (`PROPOSED`, `REJECTED`, `EXPIRED`) появятся вместе с изменениями и удалениями через AI.

### Что прочитал AI (`dataAccessed`)

AI сам запрашивает нужные данные из закрытого каталога: цели, проекты, задачи, награды (**кроме скрытых**), планы, ответы рефлексии — только этого пользователя, не больше 2 раундов. `dataAccessed` — журнал: какой запрос, сколько элементов отдано и зачем AI их просил. Содержимое не хранится. Пусто — AI ничего не читал.

ID сущностей AI не видит — только временные дескрипторы на время запроса. С ними AI может добавлять новые проекты и задачи в **существующие** цели и проекты (они не попадают в отчёт: создаются только новые).

### Отчёт (`report`)

Что сделано. Строится сервером по фактическому результату, а не по тексту AI; деталей «было → стало» нет.

```json
"report": [
  { "itemId": "g1",       "result": "CREATED", "type": "GOAL",    "id": "1c9e…", "title": "Выучить английский" },
  { "itemId": "g1.p1",    "result": "CREATED", "type": "PROJECT", "id": "a41d…", "title": "Грамматика" },
  { "itemId": "g1.p1.t1", "result": "CREATED", "type": "TASK",    "id": "6b2f…", "title": "Времена Simple" },
  { "itemId": "r1",       "result": "CREATED", "type": "REWARD",  "id": "9f3a…", "title": "Кино" }
]
```

| Поле | Описание |
|------|----------|
| `itemId` | Место в плане: `g1` — цель, `g1.p1` — её проект, `g1.p1.t1` — задача проекта, `g1.t1` — задача цели, `p1`, `t1`, `r1` — проект, задача, награда без цели |
| `result` | `CREATED` |
| `type` | `GOAL`, `PROJECT`, `TASK`, `REWARD` — по `type` + `id` фронтенд строит ссылку |

Что создаёт AI: не больше 1 цели, 10 проектов, 10 задач в одном узле, 30 задач, 3 наград — всего 40 (`AI_MAX_*`). Награды — только видимые. Задачам назначаются стандартные вопросы рефлексии, как при ручном создании.

## POST /ai/requests

```http
POST /ai/requests
Idempotency-Key: 5b0c2c0e-9d1a-4c1e-a3a4-0d7d3c2c1f00

{ "message": "Какие задачи я чаще всего просрочиваю?" }
```

| Поле | Правила |
|------|---------|
| `Idempotency-Key` (заголовок) | Обязателен: 1–100 символов, `A-Z a-z 0-9 - _`. Новый на каждое новое сообщение; тот же — при повторе после таймаута |
| `message` | Обязательно, до 2000 символов (`AI_MESSAGE_MAX_LENGTH`) |

Сервер не хранит текст сообщения — только длину и хеш. Ответ AI может занять до 90 секунд.

**Ответ `201`** — запрос со статусом `ANSWERED`, `NEEDS_CLARIFICATION` или `EXECUTED`.

**Повтор с тем же `Idempotency-Key`** — AI не вызывается снова: **`200`** с тем же телом или та же ошибка.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Нет заголовка, пустое или длинное сообщение |
| 403 `AI_CONSENT_REQUIRED` | Нет согласия |
| 409 `AI_REQUEST_IN_PROGRESS` | Ещё обрабатывается этот или другой запрос пользователя (одновременно — один) |
| 422 `IDEMPOTENCY_KEY_REUSED` | Тот же ключ, другое сообщение |
| 422 `AI_REFUSED` | AI отказался: не про цели и задачи или операция недоступна для AI (например, «выполни задачу») |
| 422 `AI_PLAN_TOO_LARGE` | AI предложил больше, чем разрешено лимитами. Ничего не создано — сузьте запрос |
| 422 `BUSINESS_RULE_VIOLATION` | Предложение нарушило правило домена при исполнении. Ничего не создано |
| 502 `AI_INVALID_RESPONSE` | AI дважды ответил не по контракту |
| 503 `AI_PROVIDER_UNAVAILABLE` | AI недоступен |
| 504 `AI_TIMEOUT` | AI не ответил за 90 секунд (`AI_REQUEST_TIMEOUT_MS`) |

Если сервер перезапустится во время ответа AI, запрос останется `PENDING_AI` и через 90 секунд будет считаться `FAILED` (`AI_TIMEOUT`) — следующий запрос пройдёт.

## GET /ai/requests

История, новые первыми. Параметры `limit` (1–100, по умолчанию 50) и `offset`.

**Ответ `200`:** `{ "items": [ запрос, … ] }`

## GET /ai/requests/{id}

**Ответ `200`** — запрос. `404` — нет такого запроса (в том числе чужой).
