# Sounds API

Звуки событий задач для текущего пользователя. Все маршруты требуют входа. Общие правила и ошибки — [README.md](README.md).

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | [/settings/sounds](#get-settingssounds) | Звуки всех событий |
| PUT | [/settings/sounds/{event}](#put-settingssoundsevent) | Выбрать звук события |
| DELETE | [/settings/sounds/{event}](#delete-settingssoundsevent) | Вернуть звук по умолчанию |

Сервер хранит только **ключ звука**. Файлы, каталог звуков и звук по умолчанию — на стороне клиента.

| `event` | Когда |
|---------|-------|
| `TASK_CREATED` | Задача создана |
| `TASK_COMPLETED` | Задача выполнена |
| `TASK_CANCELLED` | Задача отменена |
| `TASK_REMINDER` | Наступило время напоминания (`reminderAt`) |
| `TASK_OVERDUE` | Задача стала просроченной |

Неизвестное `event` в пути — `404 NOT_FOUND`.

## Ответ (общий для всех маршрутов)

Все события по порядку таблицы; `sound: null` — звук по умолчанию.

```json
{ "items": [ { "event": "TASK_CREATED", "sound": null }, { "event": "TASK_COMPLETED", "sound": "fanfare" }, … ] }
```

---

## GET /settings/sounds

**Ответ `200`** — см. выше.

## PUT /settings/sounds/{event}

```json
{ "sound": "fanfare" }
```

`sound` — обязателен: латиница в нижнем регистре, цифры, `_`, `-`, `.`; начинается с буквы или цифры; до 100 символов.

**Ответ `200`** — все события.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Ключ не прошёл проверку |
| 404 `NOT_FOUND` | Неизвестное событие |

## DELETE /settings/sounds/{event}

Возвращает звук по умолчанию. Повторный вызов не ошибка.

**Ответ `200`** — все события. `404` — неизвестное событие.
