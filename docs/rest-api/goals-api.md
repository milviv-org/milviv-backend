# Goals API

Цели текущего пользователя. Все маршруты требуют входа. Общие правила и ошибки — [README.md](README.md).

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | [/goals](#post-goals) | Создать |
| GET | [/goals](#get-goals) | Список |
| GET | [/goals/{id}](#get-goalsid) | Одна цель |
| PUT | [/goals/{id}](#put-goalsid) | Изменить |
| DELETE | [/goals/{id}](#delete-goalsid) | Удалить |

Чужая цель неотличима от несуществующей: `404 NOT_FOUND`. Проекты и задачи цели — `GET /projects?goalId=…`, `GET /tasks?goalId=…`.

## Цель (ответ)

```json
{
  "id": "1c9e…",
  "title": "Выучить английский",
  "description": "Уровень B2",
  "version": 0,
  "createdAt": "2026-10-11T12:00:00Z",
  "updatedAt": "2026-10-11T12:00:00Z"
}
```

## Поля цели (запрос)

| Поле | Тип | Правила |
|------|-----|---------|
| `title` | string | Обязателен, до 255 символов |
| `description` | string | До 5000 символов |

---

## POST /goals

Тело — поля цели. **Ответ `201`** — цель.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Поля не прошли проверку |

## GET /goals

Цели, новые первыми. Параметры `limit` (1–100, по умолчанию 50) и `offset` (по умолчанию 0).

**Ответ `200`:** `{ "items": [ цель, … ] }`

## GET /goals/{id}

**Ответ `200`** — цель. `404` — нет такой цели.

## PUT /goals/{id}

Заменяет все поля: не переданное `description` очищается. Тело — поля цели и `version` (обязательна).

**Ответ `200`** — цель с новой `version`.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Поля не прошли проверку |
| 404 `NOT_FOUND` | Нет такой цели |
| 409 `CONFLICT` | `version` устарела. Перечитать и повторить |

## DELETE /goals/{id}

**Ответ `204`.** Проекты и задачи цели не удаляются — остаются без цели.

| Ошибка | Когда |
|--------|-------|
| 404 `NOT_FOUND` | Нет такой цели |
