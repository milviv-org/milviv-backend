# Reflection API

Вопросы и ответы рефлексии текущего пользователя. Все маршруты требуют входа. Общие правила и ошибки — [README.md](README.md).

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | [/reflection/questions](#get-reflectionquestions) | Стандартные и свои вопросы |
| POST | [/reflection/questions](#post-reflectionquestions) | Создать свой вопрос |
| PUT | [/reflection/questions/{id}](#put-reflectionquestionsid) | Изменить свой вопрос |
| DELETE | [/reflection/questions/{id}](#delete-reflectionquestionsid) | Удалить свой вопрос |
| GET | [/reflection/tasks/{id}](#get-reflectiontasksid) | Вопросы и ответы задачи |
| PUT | [/reflection/tasks/{id}/questions](#put-reflectiontasksidquestions) | Выбрать вопросы для задачи |
| POST | [/reflection/tasks/{id}/answers](#post-reflectiontasksidanswers) | Ответить после выполнения |
| GET | [/reflection/answers](#get-reflectionanswers) | Все ответы |

**Как устроено.** Новой задаче автоматически назначаются три стандартных вопроса. Набор можно заменить своими вопросами или очистить — тогда рефлексия для задачи отключена. После выполнения задачи пользователь отвечает на вопросы из её набора. Ответ хранит текст вопроса на момент ответа и не пропадает, если вопрос изменят или удалят, а задачу удалят.

## Вопрос (ответ)

```json
{ "id": "00000000-0000-0000-0000-000000000001", "text": "Что помогло выполнить задачу?", "standard": true, "createdAt": "…" }
```

Стандартные вопросы (`standard: true`) общие для всех и не меняются: для `PUT` и `DELETE` их как будто нет — `404`.

## Ответ рефлексии (ответ)

```json
{
  "id": 17,
  "taskId": "6b2f…",
  "completionId": 42,
  "questionId": "00000000-0000-0000-0000-000000000001",
  "questionText": "Что помогло выполнить задачу?",
  "answer": "Выключил уведомления",
  "createdAt": "2026-10-11T12:10:00Z"
}
```

`taskId` или `questionId` равны `null`, если задача или вопрос удалены.

## GET /reflection/questions

Стандартные первыми, затем свои.

**Ответ `200`:** `{ "items": [ вопрос, … ] }`

## POST /reflection/questions

```json
{ "text": "Сколько времени ушло?" }
```

`text` — обязателен, до 500 символов. **Ответ `201`** — вопрос.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Текст не прошёл проверку |
| 409 `CONFLICT` | Создано максимум своих вопросов — 100 (`REFLECTION_MAX_OWN_QUESTIONS`) |

## PUT /reflection/questions/{id}

Тело как у `POST`. Уже данные ответы не меняются. **Ответ `200`** — вопрос.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Текст не прошёл проверку |
| 404 `NOT_FOUND` | Нет своего вопроса с таким id (в том числе стандартный) |

## DELETE /reflection/questions/{id}

Вопрос убирается из всех задач. Ответы на него остаются. **Ответ `204`.** `404` — как у `PUT`.

## GET /reflection/tasks/{id}

**Ответ `200`:**

```json
{ "taskId": "6b2f…", "questions": [ вопрос, … ], "answers": [ ответ рефлексии, … ] }
```

`answers` — ответы на выполнение задачи; пусто, если задача не выполнена или ответов нет. `404` — нет такой задачи.

## PUT /reflection/tasks/{id}/questions

Заменяет набор вопросов задачи. Пустой список отключает рефлексию. Можно и для уже выполненной задачи — данные ответы остаются.

```json
{ "questionIds": ["00000000-0000-0000-0000-000000000002", "c7d1…"] }
```

**Ответ `200`** — как у `GET /reflection/tasks/{id}`.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Вопрос не найден (чужой или несуществующий), поле `questionIds` |
| 404 `NOT_FOUND` | Нет такой задачи |

## POST /reflection/tasks/{id}/answers

Ответы на вопросы выполненной задачи. Можно ответить не на все; оставшиеся — следующим запросом. Ответ на вопрос даётся один раз и не меняется.

```json
{ "answers": [ { "questionId": "00000000-0000-0000-0000-000000000001", "answer": "Выключил уведомления" } ] }
```

`answer` — обязателен, до 5000 символов.

**Ответ `200`** — как у `GET /reflection/tasks/{id}`.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Пустой ответ; вопрос не из набора задачи; вопрос повторяется в запросе (поле `answers`) |
| 404 `NOT_FOUND` | Нет такой задачи |
| 409 `CONFLICT` | Задача не выполнена; на вопрос уже есть ответ |

## GET /reflection/answers

Все ответы пользователя, новые первыми, в том числе по удалённым задачам. Параметры `limit` (1–100, по умолчанию 50) и `offset`.

**Ответ `200`:** `{ "items": [ ответ рефлексии, … ] }`
