# Statistics API

Статистика текущего пользователя. Все маршруты требуют входа. Ничего не хранится — всё вычисляется при запросе. Общие правила и ошибки — [README.md](README.md).

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | [/statistics/summary](#get-statisticssummary) | Сводка выполненной работы за период |
| GET | [/statistics/projects](#get-statisticsprojects) | Прогресс проектов |
| GET | [/statistics/goals](#get-statisticsgoals) | Прогресс целей |

---

## GET /statistics/summary

Считается по истории выполнения: изменение или удаление задачи сводку не меняет. Даты — по UTC.

| Параметр | Описание |
|----------|----------|
| `from` | Обязателен, `YYYY-MM-DD` |
| `to` | Обязателен, `YYYY-MM-DD`, не раньше `from`. Период — не длиннее 366 дней (`STATISTICS_MAX_DAYS`) |

**Ответ `200`:**

```json
{
  "from": "2026-10-05",
  "to": "2026-10-11",
  "total": { "completed": 12, "points": 74 },
  "byDifficulty": {
    "NOVICE": { "completed": 4, "points": 8 },
    "EXPERT": { "completed": 3, "points": 24 },
    "…": "все шесть уровней"
  },
  "deadlines": { "onTime": 7, "late": 2, "withoutDeadline": 3 },
  "plan": { "onPlannedDay": 5, "earlier": 1, "later": 3, "unplanned": 3 },
  "reschedules": { "count": 6, "tasks": 4 },
  "byDay": [ { "date": "2026-10-05", "completed": 2, "points": 10 }, "…" ],
  "byWeekday": { "MONDAY": { "completed": 2, "points": 10 }, "…": "все семь дней" }
}
```

| Поле | Что считает |
|------|-------------|
| `total` | Выполнено задач и начислено за них баллов |
| `byDifficulty` | То же по уровням сложности — все шесть, в том числе нулевые |
| `deadlines` | Вовремя (в день срока или раньше), с опозданием, без срока |
| `plan` | План против факта: в плановый день, раньше, позже, без плана. Плановая дата — последний разовый план задачи на момент выполнения |
| `reschedules` | Переносов плановой даты за период и сколько разных задач переносили (удалённые задачи во втором числе не учитываются) |
| `byDay` | Каждый день периода, в том числе пустые |
| `byWeekday` | По дням недели — все семь |

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Нет `from` или `to`, неверный формат, `to` раньше `from`, период длиннее предела |

## Прогресс (общая часть)

```json
{ "total": 4, "active": 2, "completed": 1, "cancelled": 1, "overdue": 1, "pointsEarned": 8, "progressPercent": 33 }
```

| Поле | Описание |
|------|----------|
| `total` | Задач сейчас |
| `active`, `completed`, `cancelled` | По статусам |
| `overdue` | Активные с прошедшим сроком (по дате UTC) |
| `pointsEarned` | Начислено за выполненные задачи — фактически начисленное, даже если баллы задачи потом изменили |
| `progressPercent` | Выполненные среди неотменённых, проценты вниз; `null` — неотменённых задач нет |

Считается по текущим задачам: удалённая задача из прогресса пропадает (в сводке она остаётся).

## GET /statistics/projects

Проекты, новые первыми.

| Параметр | Описание |
|----------|----------|
| `status` | `ACTIVE`, `COMPLETED` или `CANCELLED`; без параметра — все |
| `limit` | 1–100; по умолчанию 50 |
| `offset` | По умолчанию 0 |

**Ответ `200`:**

```json
{ "items": [ { "projectId": "a41d…", "title": "Подготовка к экзамену", "status": "ACTIVE", "deadline": "2026-12-01",
               "progress": { прогресс } } ] }
```

## GET /statistics/goals

Цели, новые первыми. Задачи цели — привязанные к ней напрямую и через её проекты; задача, которая и в цели, и в её проекте, считается один раз. Параметры `limit` и `offset` — как у проектов.

**Ответ `200`:**

```json
{ "items": [ { "goalId": "1c9e…", "title": "Выучить английский", "projects": 2, "progress": { прогресс } } ] }
```
