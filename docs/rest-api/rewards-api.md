# Rewards API

Награды и баллы текущего пользователя. Все маршруты требуют входа. Общие правила и ошибки — [README.md](README.md).

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | [/rewards](#post-rewards) | Создать |
| GET | [/rewards](#get-rewards) | Список |
| GET | [/rewards/{id}](#get-rewardsid) | Одна награда |
| PUT | [/rewards/{id}](#put-rewardsid) | Изменить |
| DELETE | [/rewards/{id}](#delete-rewardsid) | Удалить |
| POST | [/rewards/{id}/redeem](#post-rewardsidredeem) | Получить за баллы |
| GET | [/rewards/hidden/password](#get-rewardshiddenpassword) | Задан ли пароль скрытых наград |
| PUT | [/rewards/hidden/password](#put-rewardshiddenpassword) | Задать или сменить пароль |
| GET | [/points/balance](#get-pointsbalance) | Баланс |
| GET | [/points/history](#get-pointshistory) | История баллов |

Чужая награда неотличима от несуществующей: `404 NOT_FOUND`.

## Скрытые награды

Пароль один на все скрытые награды. Клиент передаёт его заголовком в каждом запросе, которому нужны скрытые награды:

```
X-Hidden-Rewards-Password: <пароль>
```

| Заголовок | Что происходит |
|-----------|----------------|
| Нет | Скрытых наград как будто нет: в списке их нет, по id — `404` |
| Верный пароль | Скрытые награды видны и доступны наравне с остальными |
| Неверный пароль или пароль не задан | `403 FORBIDDEN` — даже для видимых наград |

Создать скрытую награду или скрыть видимую можно только с верным паролем (иначе `403`). Неверные пароли ограничены: 5 попыток за 15 минут (`AUTH_LOGIN_*`), затем `429`.

## Награда (ответ)

```json
{
  "id": "9f3a…",
  "title": "Новая игра",
  "description": null,
  "cost": 5000,
  "hidden": false,
  "version": 0,
  "createdAt": "2026-10-11T12:00:00Z",
  "updatedAt": "2026-10-11T12:00:00Z"
}
```

## Поля награды (запрос)

| Поле | Тип | Правила |
|------|-----|---------|
| `title` | string | Обязателен, до 255 символов |
| `description` | string | До 5000 символов |
| `cost` | integer | Обязателен, 1–1 000 000 баллов |
| `hidden` | boolean | Скрытая; не передан — `false` |

## POST /rewards

Тело — поля награды. **Ответ `201`** — награда.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Поля не прошли проверку |
| 403 `FORBIDDEN` | `hidden: true` без верного пароля |

## GET /rewards

Награды, дешёвые первыми. С верным паролем — вместе со скрытыми. Параметры `limit` (1–100, по умолчанию 50) и `offset`.

**Ответ `200`:** `{ "items": [ награда, … ] }`

## GET /rewards/{id}

**Ответ `200`** — награда. `404` — нет такой награды или она скрыта, а пароля нет.

## PUT /rewards/{id}

Заменяет все поля: не переданное `hidden` делает награду видимой. Тело — поля награды и `version` (обязательна).

**Ответ `200`** — награда с новой `version`.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Поля не прошли проверку |
| 403 `FORBIDDEN` | `hidden: true` без верного пароля |
| 404 `NOT_FOUND` | Нет такой награды |
| 409 `CONFLICT` | `version` устарела. Перечитать и повторить |

## DELETE /rewards/{id}

**Ответ `204`.** История баллов сохраняется.

## POST /rewards/{id}/redeem

Списывает стоимость награды. Награда остаётся — её можно получать повторно. Баланс не может стать отрицательным. Тела нет.

**Ответ `200`:**

```json
{ "reward": { … }, "pointsSpent": 5000, "balance": 120 }
```

| Ошибка | Когда |
|--------|-------|
| 404 `NOT_FOUND` | Нет такой награды |
| 409 `CONFLICT` | Баллов меньше стоимости |

## GET /rewards/hidden/password

**Ответ `200`:** `{ "set": true }`

## PUT /rewards/hidden/password

Задаёт пароль скрытых наград или меняет его. Подтверждается паролем аккаунта — так же восстанавливается забытый пароль.

```json
{ "accountPassword": "…", "newPassword": "…" }
```

| Поле | Правила |
|------|---------|
| `accountPassword` | Обязателен |
| `newPassword` | Обязателен, 4–64 символа |

**Ответ `204`.**

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Поля не прошли проверку |
| 403 `FORBIDDEN` | Неверный пароль аккаунта |
| 429 `TOO_MANY_REQUESTS` | Исчерпаны попытки входа (общий лимит с `/auth/login`) |

## GET /points/balance

Баланс — сумма всей истории баллов.

**Ответ `200`:** `{ "balance": 120 }`

## GET /points/history

Начисления и списания, новые первыми. Параметры `limit` (1–100, по умолчанию 50) и `offset`.

**Ответ `200`:**

```json
{
  "items": [
    { "id": 42, "kind": "REWARD_REDEEMED", "amount": -5000, "reason": "Reward redeemed: Новая игра",
      "taskId": null, "rewardId": "9f3a…", "createdAt": "2026-10-11T12:00:00Z" },
    { "id": 41, "kind": "TASK_COMPLETED", "amount": 8, "reason": "Task completed: Выучить времена",
      "taskId": "6b2f…", "rewardId": null, "createdAt": "2026-10-11T11:00:00Z" }
  ]
}
```

| Поле | Описание |
|------|----------|
| `kind` | `TASK_COMPLETED` (`amount` > 0) или `REWARD_REDEEMED` (`amount` < 0) |
| `taskId`, `rewardId` | Источник записи; `null`, если объект удалён |

Записи о скрытых наградах без верного пароля: `rewardId: null`, `reason: "Hidden reward redeemed"`. Название скрытой награды в историю не записывается никогда.
