# Tasks API

Задачи текущего пользователя. Все маршруты требуют входа. Общие правила и ошибки — [README.md](README.md).

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | [/tasks](#post-tasks) | Создать |
| GET | [/tasks](#get-tasks) | Список |
| GET | [/tasks/{id}](#get-tasksid) | Одна задача |
| PUT | [/tasks/{id}](#put-tasksid) | Изменить |
| DELETE | [/tasks/{id}](#delete-tasksid) | Удалить |
| POST | [/tasks/{id}/complete](#post-tasksidcomplete) | Выполнить и получить баллы |
| POST | [/tasks/{id}/cancel](#post-tasksidcancel) | Отменить |

Чужая задача неотличима от несуществующей: `404 NOT_FOUND`.

## Задача (ответ)

```json
{
  "id": "6b2f…",
  "title": "Выучить времена Simple",
  "description": null,
  "difficulty": "EXPERT",
  "points": 8,
  "status": "ACTIVE",
  "overdue": false,
  "startDate": "2026-10-01",
  "deadline": "2026-10-20",
  "reminderAt": "2026-10-19T09:00:00Z",
  "completedAt": null,
  "projectId": null,
  "goalId": null,
  "version": 0,
  "createdAt": "2026-10-11T12:00:00Z",
  "updatedAt": "2026-10-11T12:00:00Z"
}
```

| Поле | Описание |
|------|----------|
| `difficulty` | `NOVICE` (2), `APPRENTICE` (3), `ADEPT` (5), `EXPERT` (8), `MASTER` (10), `LEGENDARY` (20) — в скобках баллы по умолчанию |
| `points` | Баллы за выполнение |
| `status` | `ACTIVE`, `COMPLETED`, `CANCELLED` |
| `overdue` | `true`, если задача активна и срок прошёл (по дате UTC) |
| `projectId`, `goalId` | Проект и цель или `null` |
| `version` | Версия; нужна для `PUT` |

## Поля задачи (запрос)

| Поле | Тип | Правила |
|------|-----|---------|
| `title` | string | Обязателен, до 255 символов |
| `description` | string | До 5000 символов |
| `difficulty` | string | Обязателен, одно из значений выше |
| `points` | integer | 1–1000. Не указан — по сложности |
| `startDate` | date | `YYYY-MM-DD`, можно в прошлом, не позже `deadline` |
| `deadline` | date | `YYYY-MM-DD`, можно в прошлом. В проекте со сроком — не позже срока проекта |
| `reminderAt` | datetime | ISO-8601 |
| `projectId` | uuid | Проект пользователя; чужой или несуществующий — `400`, поле `projectId` |
| `goalId` | uuid | Цель пользователя; чужая или несуществующая — `400`, поле `goalId`. Не зависит от цели проекта |

---

## POST /tasks

Тело — поля задачи. **Ответ `201`** — задача. Ей назначаются три стандартных вопроса рефлексии ([reflection-api.md](reflection-api.md)).

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Поля не прошли проверку; срок позже срока проекта; проект или цель не найдены |

## GET /tasks

Задачи, новые первыми.

| Параметр | Описание |
|----------|----------|
| `status` | `ACTIVE`, `COMPLETED` или `CANCELLED`; без параметра — все |
| `projectId` | Только задачи этого проекта |
| `goalId` | Только задачи этой цели |
| `limit` | Сколько вернуть, 1–100; по умолчанию 50 |
| `offset` | Сколько пропустить; по умолчанию 0 |

**Ответ `200`:** `{ "items": [ задача, … ] }`

## GET /tasks/{id}

**Ответ `200`** — задача. `404` — нет такой задачи.

## PUT /tasks/{id}

Заменяет все редактируемые поля: не переданное необязательное поле очищается — в том числе `projectId` и `goalId`. Статус не меняется. Выполненную задачу изменить можно — уже начисленные баллы остаются прежними.

Тело — поля задачи и `version` (обязательна) — версия из последнего полученного ответа.

**Ответ `200`** — задача с новой `version`.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Поля не прошли проверку; срок позже срока проекта; проект или цель не найдены |
| 404 `NOT_FOUND` | Нет такой задачи |
| 409 `CONFLICT` | `version` устарела: задачу изменили после того, как клиент её получил. Перечитать и повторить |

## DELETE /tasks/{id}

**Ответ `204`.** Начисленные баллы, история выполнения и переносов сохраняются. Планы задачи удаляются.

| Ошибка | Когда |
|--------|-------|
| 404 `NOT_FOUND` | Нет такой задачи |

## POST /tasks/{id}/complete

Отмечает активную задачу выполненной и начисляет баллы. Тела нет.

**Ответ `200`:**

```json
{ "task": { …, "status": "COMPLETED", "completedAt": "2026-10-11T12:05:00Z" }, "pointsAwarded": 8 }
```

| Ошибка | Когда |
|--------|-------|
| 404 `NOT_FOUND` | Нет такой задачи |
| 409 `CONFLICT` | Задача уже выполнена или отменена |

## POST /tasks/{id}/cancel

Отменяет активную задачу. Баллы не начисляются. Тела нет.

**Ответ `200`** — задача со `status: CANCELLED`.

| Ошибка | Когда |
|--------|-------|
| 404 `NOT_FOUND` | Нет такой задачи |
| 409 `CONFLICT` | Задача уже выполнена или отменена |
