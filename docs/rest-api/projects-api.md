# Projects API

Проекты текущего пользователя. Все маршруты требуют входа. Общие правила и ошибки — [README.md](README.md).

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | [/projects](#post-projects) | Создать |
| GET | [/projects](#get-projects) | Список |
| GET | [/projects/{id}](#get-projectsid) | Один проект |
| PUT | [/projects/{id}](#put-projectsid) | Изменить |
| DELETE | [/projects/{id}](#delete-projectsid) | Удалить |
| POST | [/projects/{id}/complete](#post-projectsidcomplete) | Завершить |
| POST | [/projects/{id}/cancel](#post-projectsidcancel) | Отменить |

Чужой проект неотличим от несуществующего: `404 NOT_FOUND`. Задачи проекта — `GET /tasks?projectId=…`. Баллов за проект нет — только за его задачи.

## Проект (ответ)

```json
{
  "id": "a41d…",
  "goalId": "1c9e…",
  "title": "Подготовка к экзамену",
  "description": null,
  "calculatedDifficulty": "ADEPT",
  "status": "ACTIVE",
  "deadline": "2026-12-01",
  "completedAt": null,
  "version": 0,
  "createdAt": "2026-10-11T12:00:00Z",
  "updatedAt": "2026-10-11T12:00:00Z"
}
```

| Поле | Описание |
|------|----------|
| `calculatedDifficulty` | Сложность, вычисленная по задачам: средний уровень неотменённых задач, округлённый. `null` — задач нет. Пользователь её не задаёт; изменение задач не меняет `version` проекта |
| `status` | `ACTIVE`, `COMPLETED`, `CANCELLED` |
| `goalId` | Цель или `null` |

## Поля проекта (запрос)

| Поле | Тип | Правила |
|------|-----|---------|
| `title` | string | Обязателен, до 255 символов |
| `description` | string | До 5000 символов |
| `deadline` | date | `YYYY-MM-DD`. Не раньше самого позднего срока задач проекта |
| `goalId` | uuid | Цель пользователя; чужая или несуществующая — `400`, поле `goalId` |

---

## POST /projects

Тело — поля проекта. **Ответ `201`** — проект.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Поля не прошли проверку, цель не найдена |

## GET /projects

Проекты, новые первыми.

| Параметр | Описание |
|----------|----------|
| `status` | `ACTIVE`, `COMPLETED` или `CANCELLED`; без параметра — все |
| `goalId` | Только проекты этой цели |
| `limit` | 1–100; по умолчанию 50 |
| `offset` | По умолчанию 0 |

**Ответ `200`:** `{ "items": [ проект, … ] }`

## GET /projects/{id}

**Ответ `200`** — проект. `404` — нет такого проекта.

## PUT /projects/{id}

Заменяет все поля: не переданное необязательное поле очищается. Статус не меняется. Тело — поля проекта и `version` (обязательна).

Чтобы перенести срок проекта раньше сроков его задач, сначала перенесите задачи.

**Ответ `200`** — проект с новой `version`.

| Ошибка | Когда |
|--------|-------|
| 400 `VALIDATION` | Поля не прошли проверку; `deadline` раньше срока задачи; цель не найдена |
| 404 `NOT_FOUND` | Нет такого проекта |
| 409 `CONFLICT` | `version` устарела. Перечитать и повторить |

## DELETE /projects/{id}

**Ответ `204`.** Задачи проекта не удаляются — остаются без проекта.

| Ошибка | Когда |
|--------|-------|
| 404 `NOT_FOUND` | Нет такого проекта |

## POST /projects/{id}/complete

Завершает активный проект. Баллов не даёт, задачи не меняет. Тела нет.

**Ответ `200`** — проект со `status: COMPLETED`.

| Ошибка | Когда |
|--------|-------|
| 404 `NOT_FOUND` | Нет такого проекта |
| 409 `CONFLICT` | Проект уже завершён или отменён |

## POST /projects/{id}/cancel

Отменяет активный проект. Задачи не меняет. Тела нет.

**Ответ `200`** — проект со `status: CANCELLED`.

| Ошибка | Когда |
|--------|-------|
| 404 `NOT_FOUND` | Нет такого проекта |
| 409 `CONFLICT` | Проект уже завершён или отменён |
